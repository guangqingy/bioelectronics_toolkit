# GitHub Repository Settings Checklist

These items are maintained in GitHub's web UI rather than in repository files:

- Enable Issues, and optionally Discussions, under Settings -> General ->
  Features.
- Protect `main` under Settings -> Branches and require CI to pass before
  merging.
- Enable Dependabot updates for pip and GitHub Actions under Settings -> Code
  security.
- Add About topics such as `electrophysiology`, `tkinter`, `flask`,
  `patch-clamp`, `emg`, `intan`, `fluorescence-microscopy`, and `abf`.
- Upload `web_static/img/social_preview.png` as the repository social preview.
- Draft the GitHub Release for `v0.2.0` using the `docs/CHANGELOG.md` notes.
